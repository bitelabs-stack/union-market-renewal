# 식자재 쇼핑몰 홈 리뉴얼 시안

UNION SOFT 사용자 제공 로고를 적용한 반응형 쇼핑몰 디자인 프로토타입입니다.

## 포함 기능
- 상품 검색, 카테고리 필터, 상품명 정렬
- 상품 상세 미리보기, 찜, 샘플 장바구니
- 벤치마크 분석 및 디자인 가이드

## 주의
이 페이지는 디자인 검토용입니다. 실제 로그인, 주문, 결제, 발주 또는 서버 저장은 연결되지 않습니다. 상품 사진과 규격, 가격은 실제 판매 정보가 아닌 시안 예시입니다.

## 제작 출처
- 화면은 HTML/CSS/JavaScript로 구현했습니다.
- 히어로 및 식품 연출 사진은 AI 생성 이미지입니다. 실제 판매 상품의 외관·구성·원산지·인증을 보증하지 않습니다.
- 로고와 키오스크 사진은 사용자 제공 원본을 사용했습니다.
- Pretendard Regular/SemiBold/ExtraBold는 SIL Open Font License 1.1을 따릅니다. FONT-LICENSE.txt를 참고하세요.

이미지와 서체를 포함한 정적 index.html 단일 파일로 게시합니다.
